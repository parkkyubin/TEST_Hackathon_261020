# TC4 — V4 공연 입장 마감 앞당김 (18:40 → 18:00)

작성 2026-10-20 13:18~ (코드 열람 전)

## 입력 변경값
D02 C 입장 마감 **18:00** (USER). 공연 시작 19:00은 그대로.

## Hard 조건
| CH | 기대 | 근거 |
|---|---|---|
| CH1 | **C 도착 ≤ 18:00** (선언 기준). O→C 20~30분 → O 출발 max 기준 ≤17:30 | CALC(D03, USER) |
| CH4 | O 포함 시 O 도착 ≤18:00이지만 실질 제약은 17:30 출발 | D02 |
| 기타 | CH2·CH3·CH6 유지 | |

## 기대 방향 (TC0 대비)
| 항목 | 기대 | 판정 기준 | 근거 |
|---|---|---|---|
| 오후(P·O) | **대폭 축소, O 생략 가능** | O·P 합계 체류 < TC0. 18:00 넘는 C 도착 계획이 "가능"으로 나오면 **Fail(Hard 위반)** | V4, D02, F03 |
| 출력 마감값 | 18:00이 표시되고 출처 USER | 18:40이 그대로 출력되면 하드코딩(R7) Fail | R6, R7 |
| M, R | 유지 | | |
- O 생략 시 P→C 직행 시간은 Unknown(U07) → 확정 계산 금지, Unknown 표시.

## 반드시 나와야 할 출처 ID
USER(마감), D02, D03, D06

## 반드시 나와야 할 Human check
H01, H03, H06. O/P 생략 시 H08(P). 택시 시 H04.

## 나오면 안 되는 표현
E10 전부. "18:00까지 확실히 도착"(확정형).
