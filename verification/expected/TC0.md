# TC0 — 기본 입력 (D01~D08 그대로)

작성 2026-10-20 13:18~ (코드 열람 전). 공통 기준: `00_공통기준.md`

## 입력 변경값
없음 (D01~D08 기본값). 체류·식사시간·요금(A02~A04, A08)은 미정 → 프로그램 기본값 사용 시 그 값과 `ASM` 표시를 actual에 기록.
