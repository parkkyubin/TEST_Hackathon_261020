## 구성 방법
프로그램이 계산하는 "도착 예상 시각"은 체류시간 기본값(HB4 미정) 등 구현에 따라 달라지므로, 정확한 입력 수치는 **TC0 실제 출력을 본 뒤** 한 개의 값(해당 구간 이동시간 max, 또는 마감 시각)을 조정해 계산 도착 max가 마감 −1분 / 정각 / +1분이 되도록 만든다. 사용한 수치는 `actual/BV_*`에 기록. **판정 기준은 아래와 같이 지금 고정**한다.

판정 기준(공통, J3·J4):
- 도착 max ≤ 마감 → 해당 Hard **충족** 표시 (정각 = 충족)
- 도착 max > 마감 → (a) 일정을 조정해 max ≤ 마감으로 만들거나 (b) **위반/위험 경고**. "충족"으로 표시하면 **Fail**
- min ≤ 마감 < max → 선언 기준(HB3)과 무관하게 **위험(불확실)** 표시 필요. 확정 "충족"이면 Fail (R8)
