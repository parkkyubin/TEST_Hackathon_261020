# TC6 — V6 예산 축소 (6만 원 → 2만 원)

작성 2026-10-20 13:18~ (코드 열람 전)

## 입력 변경값
D07 이동비 4명 합계 **20,000원** (USER).

## Hard 조건
CH1~CH6 충족. 예산은 **Soft(CS1)** 이므로 예산 때문에 CH1을 깨는 계획은 Fail(CH1 > CS1). — §3 우선순위

## 기대 방향 (TC0 대비)
| 항목 | 기대 | 판정 기준 | 근거 |
|---|---|---|---|
| 택시 | **비추천/불가 또는 예산 초과 경고** | 요금이 미정(A08, U03)이면 "택시 가능"이라고 확정 금지 → Unknown + H04. 요금이 입력돼 있다면 > 2만 원 시 제외/경고 | D07, A07, A08, HB6 |
| P→O | 지하철/버스 위주. 그에 따라 P 축소 또는 O 축소로 CH1 보호 | | D06, D02 |
| 출력 예산값 | 20,000원, 출처 USER | 60,000원 그대로면 R7 Fail | R7 |
- TC0에서 택시가 추천되지 않았다면 결과 차이는 예산 표시뿐일 수 있음 → "부분 변화"로 기록, Fail 아님.

## 반드시 나와야 할 출처 ID
USER, D07, D06, ASM(요금 가정 사용 시)

## 반드시 나와야 할 Human check
**H04**(예산 범위 합의), H03, H01, H06

## 나오면 안 되는 표현
E10 전부. 요금 미정인데 "택시비 N원"을 확정 사실로 표기.
